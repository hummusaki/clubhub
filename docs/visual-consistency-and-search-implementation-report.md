## Search and navigation

- **Search ClubHub…** works on Overview, Tasks, Calendar, Availability, Clubs, Resources, and Settings. It groups public clubs, membership-scoped calendar events, resources from the public catalog and the user’s own resources, and public roster officers. Private tasks, polls, workspace people, and contact information are outside the global index.
- Selecting a result opens its destination with the exact record focused. That selected record can be seen even when a local filter would otherwise hide it. Calendar, Clubs, and Resources keep separate page filters; Tasks continues to use its saved account preferences. Availability and Settings have global search without added task, poll, or settings search indexes.
- **Find clubs** opens the same dialog from Overview and Clubs → Discover. Its query and refinements survive reopening and are independent of the header query. Optional assistant suggestions use only validated candidate IDs; free-form model claims are ignored and the deterministic club results stay in place.
